## Email setup
The site uses Formspree for the message form.

1. Create a Formspree form using the email `mohahmedshahid@gmail.com`.
2. Copy the endpoint they provide.
3. Open `script.js`.
4. Replace `YOUR_FORMSPREE_ENDPOINT` with your endpoint.
5. Upload the files to GitHub and enable GitHub Pages.

The email address itself is not exposed in the JavaScript; Formspree handles delivery.
